From Messy to Market-Ready: E-Commerce Data Cleaning & Analysis

This project uses Python and Pandas to clean, validate, and analyze messy e-commerce transaction data, with the final dataset used for Power BI reporting.

Workflow: Raw Data → Data Profiling → Data Cleaning → Data Validation → Dashboard → Business Analysis

Objectives

Data Quality

  • Identify missing, duplicate, inconsistent, and invalid data.
  • Standardize data formats.
  • Validate numerical calculations and categorization.
  • Flag inconsistent or suspicious entries for manual review.

Business Analysis

  • Analyze revenue trends over time across products and categories.
  • Investigate return and cancellation rates to uncover underlying drivers.
  • Identify preferred payment methods and purchasing patterns.
  • Examine unusual transactions and missing data to assess potential business impact.

3. Data Cleaning


Clean formatting inconsistencies, standardize values, convert data types, and address invalid or missing values identified during profiling.


3.1 Column and Text Formatting


Remove leading spaces from column names and text values, then standardize product names so differently formatted versions of the same product are combined during analysis.



  

    
In [ ]:

    
# Store original values
original_columns = df.columns.copy()
original_product = df['Product'].copy()

# Remove leading and trailing spaces from column names
df.columns = df.columns.str.strip()

# Remove leading and trailing spaces from text values
text_columns = df.select_dtypes(include='object').columns

for col in text_columns:
    df[col] = df[col].str.strip()

# Standardize product names with different capitalization
product_groups = df['Product'].dropna().groupby(
    df['Product'].dropna().str.lower()
)

for _, group in product_groups:
    preferred = group[group.str[0].str.isupper()].iloc[0] if any(
        group.str[0].str.isupper()
    ) else group.iloc[0]

    df.loc[df['Product'].str.lower() == group.iloc[0].lower(), 'Product'] = preferred

# Show changes
print("Column name changes:")
for old, new in zip(original_columns, df.columns):
    if old != new:
        print(f'"{old}" → "{new}"')

print("\nProduct name changes:")
changes = pd.DataFrame({
    'Before': original_product,
    'After': df['Product']
})

changes = changes[changes['Before'] != changes['After']].drop_duplicates()

for _, row in changes.iterrows():
    print(f'"{row["Before"]}" → "{row["After"]}"')

3.3 Numeric Data Issues


3.3.1 Non-numeric Values


The non-numeric values were assumed to be data-entry errors. Some non-numeric values can be safely corrected based on their formatting or written representation. Values that cannot be reliably interpreted are retained as missing.



  

    
In [ ]:

    
# Store original values
quantity_bad = df['Quantity'][quantity_numeric.isna() & df['Quantity'].notna()]
price_bad    = df['Price'][price_numeric.isna() & df['Price'].notna()]

# Handle written numeric value as an exception
df['Price'] = df['Price'].replace({'four hundred': '400'})

# Extract numeric values from formatting errors
df['Quantity'] = pd.to_numeric(
    df['Quantity'].astype(str).str.extract(r'(\d+\.?\d*)')[0],
    errors='coerce'
)
df['Price'] = pd.to_numeric(
    df['Price'].astype(str).str.extract(r'(\d+\.?\d*)')[0],
    errors='coerce'
)

# Display before → after changes
for val in quantity_bad:
    fixed = pd.Series([str(val)]).str.extract(r'(\d+\.?\d*)')[0].iloc[0]

for val in price_bad:
    mapped = '400' if str(val) == 'four hundred' else str(val)
    fixed  = pd.Series([mapped]).str.extract(r'(\d+\.?\d*)')[0].iloc[0]

3.3.3 Missing Numeric Values

Missing Price values are imputed using the median of each product, since prices vary substantially across products and a single overall median would not provide an appropriate estimate.
